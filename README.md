# Web Project 2 — список задач

Лабораторная работа №2 по дисциплине web-программирование.

[Открыть приложение](https://emptyshka.github.io/web-project2/)

## Возможности

- Добавление задач с названием и датой, проверка обязательных полей и названия из пробелов.
- Редактирование названия и даты с возможностью отмены.
- Удаление задачи и отметка выполнения с изменением оформления.
- Поиск по названию без учёта регистра, фильтры по статусу и дате.
- Сортировка по дате в обоих направлениях.
- Изменение порядка перетаскиванием за значок ⠿ или кнопками ↑/↓.
- Сохранение задач, статуса и порядка в браузере через `localStorage`.
- Адаптивный интерфейс для телефона и компьютера.

Для изменения порядка выберите «Свой порядок» и сбросьте поиск и фильтры.
Это можно сделать кнопкой «Сбросить фильтры».

## Локальный запуск

Нужны браузер и Python 3. Устанавливать дополнительные пакеты не требуется.

```sh
git clone https://github.com/emptyshka/web-project2.git
cd web-project2
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте в браузере `http://127.0.0.1:8765/`.
Чтобы остановить сервер, нажмите `Ctrl+C` в терминале.

# Web Project 2 — список задач

Лабораторная работа №2 по дисциплине «Веб-программирование».
Приложение выполнено на чистом JavaScript с использованием DOM API и CSS, без фреймворков.

- [Открыть приложение](https://emptyshka.github.io/web-project2/)
- [Репозиторий](https://github.com/emptyshka/web-project2)
- [Задание преподавателя](https://github.com/Dasha2101/WEB2025Q26LB2)

## Возможности

- Добавление задач с названием и датой; проверка обязательных полей и названия из пробелов.
- Редактирование названия и даты с возможностью отмены.
- Удаление задачи и отметка выполнения с изменением оформления.
- Поиск по названию без учёта регистра, фильтры по статусу и точной дате.
- Сортировка по дате в обоих направлениях.
- Изменение порядка перетаскиванием за значок ⠿ или кнопками ↑/↓.
- Сохранение задач, статуса и ручного порядка в `localStorage`.
- Адаптивный интерфейс для узкого и широкого экрана.

Для ручного перемещения выберите «Свой порядок» и сбросьте поиск и фильтры.
Кнопка «Сбросить фильтры» возвращает все эти настройки одновременно.
При активной фильтрации или сортировке по дате перемещение отключено, чтобы скрытые задачи
не участвовали в неоднозначной перестановке. Перетаскивание реализовано через события указателя;
кнопками перемещения также можно пользоваться с клавиатуры.

## Локальный запуск

Нужны браузер и Python 3. Устанавливать пакеты или собирать проект не требуется.

```sh
git clone https://github.com/emptyshka/web-project2.git
cd web-project2
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте [локальное приложение](http://127.0.0.1:8765/).
Чтобы остановить сервер, нажмите `Ctrl+C` в терминале.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Базовый каркас и подключения CSS и скриптов; `body` изначально пустой |
| `script.js` | Создание интерфейса через DOM API, обработчики формы и действий пользователя |
| `storage.js` | Чтение, проверка структуры и сохранение задач |
| `filters.js` | Поиск, фильтрация и сортировка отображаемого списка |
| `reorder.js` | Расчёт нового ручного порядка задач |
| `style.css` | Оформление, состояния элементов и адаптивность |
| `tests/` | Браузерные проверки, протокол и снимок результата |

Все элементы интерфейса создаются через `document.createElement` и добавляются методами DOM.
Пользовательские названия выводятся через `textContent`.
Сортировка и фильтрация работают с отдельным массивом отображения, сохраняя исходный ручной порядок.

## Проверки

Из корня проекта запустите отдельный тестовый сервер:

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

Откройте [браузерные проверки](http://127.0.0.1:8766/tests/) и нажмите «Запустить проверки».
Набор использует отдельный origin и не запускается поверх существующих непустых данных.
Не запускайте несколько экземпляров проверок одновременно на одном origin.

Результат локального прогона 4 ноября 2026 года: **12 проверок пройдено, 0 ошибок**.
Проверены создание, редактирование, отмена, статус, удаление, совместные фильтры,
обе сортировки, сохранение и восстановление после настоящей перезагрузки, повреждённые данные
и сохранность постороннего ключа хранилища.

Дополнительно вручную проверены перенос мышью вверх/вниз, восстановление порядка,
отображение на ширинах 320, 390, 768 и 1440 пикселей, включая название из 120 символов,
и отсутствие ошибок JavaScript в консоли. Проверки выполнены во встроенном браузере Codex;
физический телефон и другие браузеры в этом прогоне не использовались.

[Подробный протокол и снимок результата](tests/RESULTS.md).

## Хранение данных

Задачи сохраняются в ключе `web-project2.tasks` в браузере для текущего origin.
Данные локального адреса и GitHub Pages хранятся отдельно; между устройствами и браузерами
они не синхронизируются. При очистке хранилища браузера задачи также исчезнут.

Если сохранённые данные повреждены или хранилище недоступно, приложение показывает предупреждение.
Непрочитанное исходное значение не перезаписывается; новые изменения в такой вкладке могут
не сохраниться. При ошибке записи задачи остаются доступны в текущей вкладке, а пользователь
получает сообщение о возможной потере изменений после перезагрузки.
